# Patologia · DemoQuest

Prototipo de sistema de gestión para laboratorio de anatomía patológica.

## Cómo iniciar

```bash
npm install
npm run dev
```

Abre http://localhost:3000

1. Regístrate como patólogo
2. Crea casos en Seguimiento
3. Cada cuenta solo ve sus propios casos
4. Informe con firma del patólogo logueado
